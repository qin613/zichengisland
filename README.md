# 🏝️ 自成岛 · ZICHENG ISLAND

> 构建独属于自己的成长小岛，收纳旅行、美食、爱好、学习。
> 一款玻璃拟态风格的综合性生活工具箱网页应用，集日常工具、学习助手、娱乐于一体。

---

## ✨ 功能模块

### 🏠 首页仪表盘 `/`

**入口即景** — 进入自成岛先看到问候语（根据时段自动切换早上好/下午好/晚上好）、当天日期（含星期）、欢迎语"欢迎来到自成岛，让每一天都充满美好"。

- **🌤️ 天气卡片** — 自动定位获取当地天气（默认北京），显示温度、体感温度、湿度
- **✨ 功能模块入口** — 9个模块的玻璃拟态卡片，点击即跳转
- **💬 每日一句** — 随机展示古诗词/名言
- **📝 今日待办预览** — 展示前4条待办，点击"查看全部"进入效率模块
- **🖼️ 每日美图** — 15张Unsplash自然风光按日期轮换

- **📖 详情弹窗** — 查看完整步骤、食材列表、来源链接

- **🔊 主音量** — 统一控制总输出
- **⏲️ 专注计时器** — 15/25/45/60分钟预设，结束后自动停止音效并响铃提示

- **🔍 搜索歌曲** — 关键词搜索，支持播放、查看详情

- **📻 歌单详情** — 查看歌单内歌曲列表并播放
- **🎵 全局播放器** — 跨路由不中断播放，迷你播放栏 + 全屏歌词播放器

## 🚀 快速开始

### 前置要求

- [Node.js](https://nodejs.org/) ≥ 18
- npm ≥ 9

### 前端（自成岛主应用）

```bash
# 进入前端目录
cd app

# 安装依赖
npm install

# 启动开发服务器（默认端口 5173）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

### 后端（AI 拆解模块）

```bash
cd backend

# 安装依赖
npm install

# 配置 DeepSeek API Key
cp .env.example .env
# 编辑 .env，填入你的 API Key

# 启动后端服务（端口 3000）
npm start
```

> ⚠️ **注意**：前端 Vite 开发服务器会将 `/api` 请求代理到后端 `localhost:3000`。如遇代理问题（Windows 环境），前端 API 会自动直连后端端口。

## 🤖 AI 拆解模块

1. 在输入框用自然语言描述任务（如"开发一个REST API后端"）

3. 每个子任务包含：标题、描述、优先级（高/中/低）、预估耗时、依赖关系

6. 支持 Markdown（含勾选框）和 JSON 两种格式导出
7. 后端健康检查自动检测 API 配置状态

## 📝 自定义

### 添加/替换背景音乐

将 `other.mp3` 和 `learning.mp3` 放入 `public/sounds/` 目录即可。路由自动切换逻辑在 `src/composables/useBackgroundMusic.js` 中。

### 添加环境音效

1. 在 `src/data/sounds.js` 中注册新音效配置（含 id、name、icon、filename 等）
2. 将音频文件（mp3）放入 `public/sounds/`
3. 音乐模块自动识别并显示新音源

### 修改主题色

编辑 `src/assets/styles/variables.css` 中的 CSS 变量，主色调为 `--color-primary: #d4a373`（暖沙金）。

### 添加运动动作

编辑 `src/data/sportsData.js`，在 `EXERCISES` 数组中添加新动作，可指定 `bvid` 关联 B站教学视频。
