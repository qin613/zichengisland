# 🌌 生活小站 · Life Hub

> 深空星空主题的综合性生活技巧网页 —— 让每一天都充满美好

一个基于 Vue 3 的纯前端应用，集成 **八大功能模块**：做饭、音乐、旅游、效率、健康、运动、学习、首页仪表盘。深邃的动态星空背景配合毛玻璃卡片，带来沉浸式的视觉体验。

> **v2.0 新版** 🎯 学习模块全面升级：7 大考研/408科目 × 三级难度 × 海量题库 × 错题本 × B站视频课

---

## ✨ 项目预览

- 🌠 **动态星空背景**：Canvas 绘制 200+ 颗闪烁星星 + 偶发流星划过 + 缓慢漂移动画
- 🍳 **做饭模块**：中英双语食谱库（36 道中文家常菜 + TheMealDB 全球食谱），按菜名/食材搜索、分类筛选、随机推荐、收藏夹。中文食谱配有高清食物图片和 emoji 渐变色回退
- 🎵 **音乐模块**：白噪音混音播放器，多音源叠加、场景预设、专注计时器联动
- ✈️ **旅游模块**：156 个国家浏览（国旗图片 + 国家详情），**中国 34 个省份下钻**（景点、美食、旅行贴士），行李清单、旅行预算计算器
- ⏱️ **效率模块**：番茄钟（进度环动画）、待办清单（优先级）、习惯打卡（连续天数）
- 💧 **健康模块**：饮水记录（进度环）、体重趋势（SVG 折线图）、睡眠日志
- 🏋️ **运动模块**：预设健身计划、动作库、计时器、训练记录
- 📚 **学习模块**：**7 大考研/408科目**（高等数学、线性代数、英语、数据结构、计算机组成原理、操作系统、计算机网络），每科**三级难度**（基础/进阶/挑战），**4 种题型**（选择/填空/计算/分析），英语细分**考研/四级/六级**三子类别。**错题本**智能复习、成绩追踪。**视频课**功能内嵌 B站优质课程，边看边学
- 📷 **每日美图**：Unsplash 精选自然风光，每天自动更换，电影级宽屏封面

## 🚀 快速开始

```bash
# 进入项目目录
cd life-hub

# 安装依赖
npm install

# 启动开发服务器
npm run dev
# 浏览器自动打开 http://localhost:5173

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

**环境要求**：Node.js ≥ 18，npm ≥ 9

## 🛠️ 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Vue 3 | 3.5+ | 前端框架（Composition API + `<script setup>`）|
| Vite | 6.x | 构建工具，极速热更新 |
| Vue Router | 4.x | 页面路由，懒加载 |
| Pinia | 2.x | 跨模块状态管理 |
| Web Audio API | - | 白噪音实时合成与混音 |
| Canvas API | - | 动态星空背景绘制 |
| SVG | - | 图表（体重趋势、番茄钟环、饮水环）|

| 原生 fetch | - | API 请求，零依赖 |

**零外部 UI 库**——所有组件、样式、动画均手写实现。

## 📚 学习模块（v2.0 全新升级）

| 科目 | 级别 | 题库量 | 视频课 |

### 功能特性

- **题库系统**：每科三级难度（基础→进阶→挑战），四种题型（选择题、填空题、计算题、分析题）
- **答题模式**：逐题作答、即时反馈、详细解析，答题进度可视化
- **成绩统计**：每科每难度独立追踪答题数、正确率，可视化学习进度
- **错题本**：自动收录错题，支持按科目筛选、分组复习，答对自动移除
- **英语子类别**：英语科目细分为考研英语、四级英语、六级英语，独立题库和进度
- **视频课程**：每科嵌入 B站优质免费课程（宋浩·高等数学、王卓·数据结构、刘宏伟·计组、王道·操作系统、湖科大·计算机网络等），支持选集播放、全屏观看

### 数据持久化

所有学习进度、错题记录存储在浏览器 `localStorage`，关闭页面不丢失。

## 🎵 白噪音说明

音乐模块的音源分两种：

### 程序合成（无需文件，打开即用）
| 音源 | 说明 |
|------|------|
| 白噪音 | 全频段均匀，类似电视雪花 |
| 粉噪音 | 比白噪音更柔和，适合助眠 |
| 棕噪音 | 低沉浑厚，类似远处海浪 |

以上三种由浏览器 Web Audio API 实时算法合成，**零文件依赖**。

### 自然音效（需要音频文件）
| 音效 | 文件名 |
|------|--------|
| 雨声 | `rain.mp3` |
| 海浪 | `ocean.mp3` |
| 森林 | `forest.mp3` |
| 篝火 | `fire.mp3` |
| 咖啡馆 | `cafe.mp3` |
| 风声 | `wind.mp3` |

从以下免版权站点下载后放入 `public/sounds/` 目录即可：
- [Mixkit](https://mixkit.co/free-sound-effects/) — 免费可商用
- [Freesound](https://freesound.org/) — CC 协议

文件缺失时 UI 会提示"音频文件缺失"，**不影响其他功能**。

## 🎨 设计规范

### 深空星空主题

| 元素 | 说明 |
|------|------|
| 背景 | 深紫 → 深蓝 → 墨黑渐变 + 缓慢流动的星云光晕 |
| 星空 | Canvas 绘制：200+ 闪烁星星 + 大星十字光芒 + 偶发流星 |
| 卡片 | `rgba(30,35,75,0.35)` 毛玻璃 + `backdrop-filter: blur(20px)` |
| 主色 | 星辰紫 `#7c6cff` · 极光青 `#5ed4e6` · 玫瑰星云粉 `#ff7eb3` |
| 文字 | `#f0f3ff` 主色 · `rgba(220,225,255,0.75)` 次要 |
| 圆角 | 统一 20px 大圆角 |
| 动效 | 卡片 hover 上浮 · 路由淡入淡出 · 星星闪烁 · 流星划过 |

### 响应式断点

| 屏幕 | 布局 |
|------|------|
| > 1024px | 三列 / 四列网格 |
| 768px ~ 1024px | 两列网格 |
| < 768px | 单列，汉堡菜单 |

## 🖼️ 图片说明

- **中文食谱**：部分菜品使用 Wikimedia Commons 真实菜品图片，部分菜品因无合适图片资源改用 **emoji + 渐变色** 作为视觉标识，所有图片加载失败时自动回退到 emoji 显示
- **国家国旗**：使用 [FlagCDN](https://flagcdn.com/) 的 PNG 国旗图片，加载失败自动回退到 emoji 国旗
- **中国省份**：全部使用 **emoji + 渐变色** 作为卡片主视觉，每省搭配专属主题色
